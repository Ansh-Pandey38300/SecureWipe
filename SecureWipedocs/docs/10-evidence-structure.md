# Evidence Structure

Status: Just started — folder structure created, EvidenceItem design only planned, nothing implemented yet.

## What exists
An initial evidence folder structure was created. The plan is to represent evidence with a structured EvidenceItem (not unstructured logs), so device detection, sanitization, verification, and certificate results can eventually be recorded in a traceable, consistent way.

## Not built yet
The actual EvidenceItem structure, and connecting it to real detection/sanitization/verification output.
